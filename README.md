# 수치해석 기법의 구현과 오차 분석

**기간**

- E1–E2: 2024.03.25 – 2024.04.14
- E3–E4: 2024.05.02 – 2024.05.26

## 개요

Taylor 급수, 근 찾기, 선형 연립방정식, 회귀의 고전 수치해석 기법을 SciPy 없이
NumPy로 직접 구현하고, E1–E3에서는 오차를, E4에서는 `R²`를 측정한다. E3의 역행렬 풀이,
E4의 정규방정식 풀이, 조건수·고유값 계산에는 `numpy.linalg`를 사용한다. 네 실험은 서로 독립적이다. 네 실험의
설정, 전체 결과 표, 관찰은 [`docs/experiment-log.md`](docs/experiment-log.md)(이하
로그)에 기록한다.

## 실험 구성

| 실험 | 주제 | 설정 |
| --- | --- | --- |
| E1 | Taylor 급수 | `sin(x)`를 `π/6`에서 전개, `x = π/6 + 0.005`에서 차수 0–10 |
| E2 | 근 찾기 | `f(x) = (x−1)(x−2)(x−3)`의 근 3, 이분법(구간 [2.5, 4])·고정점 반복(`g(x) = 6/11 + 6/11·x² − 1/11·x³`, `x0 = 2.5`)·Newton-Raphson(`x0 = 4`), 방법별 15개 기록(이분법은 15회 반복, 나머지는 시작값 `x0`와 14회 반복) |
| E3 | 선형 연립방정식 | 대각이 `δ = 10⁻ⁿ`(`n = 1–16`)인 4×4 연립방정식, 풀이법 5종, 반올림 연구(아래 E3) |
| E4 | 분포 회귀 | `N(0, 4²)` 표본 100개의 경험적 CDF를 무작위 15점(`x ~ U[−10, 10)`)에서 모델 5종으로 적합, seed 100개 |

- **오차:** 참 백분율 상대오차 `ε_t = |(참값 − 근삿값) / 참값| · 100`(%), 근사 백분율
  상대오차 `ε_a = |(현재 − 이전) / 현재| · 100`(%).
- **표기:** 측정값은 유효숫자 4자리, 근삿값(다항식 값, 반복값, 해의 성분)은 float64 전체 자릿수, 개수는 정수로 표기한다.
  측정값 `0`은 float64에서 정확히 0, `nan`은 계산 결과가 NaN임을 뜻한다.
- 행렬, 풀이법, 모델, 정지 조건 등 설정의 정의는 로그의 Conventions와 각 실험의 Setting에 있다.

### E3: 선형 연립방정식

*참 백분율 상대오차 `ε_t`(%)의 네 성분 중 최댓값. 기준은 float64 입력값을 유리수 연산으로 푼 정확해를
float64로 변환한 값이다.
`n` 16개 중 6개와 역행렬 풀이를 뺀 풀이법만 표시하며, 전체 결과는 로그 E3-b에 있다. 조건수는 2-노름
조건수이다. Gauss-Seidel은 허용오차 1%, 최대 1000 sweep으로 반복하며, 반복 행렬의 spectral radius와
반복 횟수는 로그 E3-c에 있다.*

*반올림 연구: 단순 가우스 소거와 partial pivoting을 `n` = 1, 2, 4, 8에서 소거 승수, 갱신된 확대행렬 `[A | b]`의
성분, 후진대입 결과를 소수점 아래 `k` = 1, 2, 3, 4, 6, 8자리로 반올림해 푼다. 반올림 방식은 로그 E3 Setting에, 결과는 로그
E3-d, E3-e에 있다.*

| 12 | 13.42 | 0.09771 | 2.220e-14 | nan | nan |
| 15 | 13.42 | 11.18 | 2.220e-14 | nan | nan |

- 행렬의 조건수는 모든 `n`에서 13.42–14.94이다. 단순 가우스 소거의 오차는 `n = 1`의

- Gauss-Seidel 반복 행렬의 spectral radius는 모든 `n`에서 1.091e+05(이완 1),
  6.830e+04(이완 0.9) 이상이며, 모든 실행이 최대 1000 sweep을 모두 쓰고 nan으로 끝났다.

### E4: 분포 회귀

*seed 100개(0–99)에서의 `R²`. 표준편차는 모집단 표준편차(ddof = 0)이다. 모델식과 `R²`의 정의는
로그 E4 Setting에, 최소–최대와 실패한 적합 수는 로그 E4-b에, seed 0의 값은 로그 E4-a에 있다.*

| 모델 | `R²` 평균 ± 표준편차 | 중앙값 | `R²`가 가장 높은 seed 수 |
| --- | --- | --- | --- |
| 선형 | 0.9643 ± 0.01392 | 0.9654 | 0 / 100 |
| 2차 다항식 | 0.9724 ± 0.01162 | 0.9734 | 6 / 100 |
| 지수(2차) | 0.9774 ± 0.02529 | 0.9847 | 15 / 100 |
| 거듭제곱(`x + 10`) | 0.8609 ± 0.1239 | 0.8906 | 0 / 100 |
| **sigmoid** | **0.9934 ± 0.005766** | **0.9954** | **79 / 100** |
